# What is this repository about
This repository is aimed to reproduct results and extend research from the article Recommender Systems with Generative Retrieval (arXiv:2305.05065)

# How to run experiments

Edit corresponding configuration file, install dependencies and run:

`
python -m main.py path/to/config.yaml
`

# How to make your own configuration

Each configuration file should always define `model: MODEL NAME`. Other arguments are up to you
